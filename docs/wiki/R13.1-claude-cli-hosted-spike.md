Measures whether the `claude` CLI can be driven as a hosted, multi-turn session before `docs/decisions/ADR-0007-remote-conversation-and-hosted-sessions.md` §3a is built on. Task brief: `docs/plan/tasks/R13.1.md`. Full findings: `docs/plan/verification-notes.md` §143.

## Verdict

**Separate-invocation chaining is viable; multi-turn stdin is unestablished.**

The `-p` flag exits after exactly one turn. Multi-turn stdin (`--input-format stream-json --output-format stream-json`) could NOT be reproduced under standalone conditions despite claims. However, `--continue` and `--resume <session-id>` reliably chain separate `-p` processes into a single session with stable IDs. This is exactly what `src/tasks/resume.ts` already implements.

## Eight-item summary

| # | Topic | Label | Key finding |
|---|---|---|---|
| 1 | Single-turn exit | [OBSERVED] | `-p` always exits after 1 turn |
| 2 | Stream-json output | [OBSERVED] | Requires `--verbose`, ~40 JSONL lines/turn |
| 3 | Interruption | [OBSERVED, caveats] | SIGINT unreliable on Windows; process-kill required |
| 4 | Resume/identity | [OBSERVED] | Session ID stable across invocations; history preserved |
| 5 | Project scope + hooks | [OBSERVED] | Golem PostToolUse hooks fire in non-bare `-p`; invariant 2 enforceable |
| 6 | Permissions | [OBSERVED] | default/bypassPermissions work; PreToolUse can block execution |
| 7 | Proxy interposition | [UNESTABLISHED] | Direct proxy hung; normal repo-root runs go through proxy |
| 8 | Cost/lifetime | [OBSERVED] | $0.15/base, $0.34 with hook overhead; idle cost zero |

## Recommendation

Build R13.3 as a pipeline of fork/exec processes matching existing `resume.ts` pattern. Do not attempt persistent daemon or multi-turn stdin. Neither the Agent SDK nor Golem's own agentic loop should be built without explicit USER DECISION.
