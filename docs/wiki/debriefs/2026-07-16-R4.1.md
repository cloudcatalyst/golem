Shipped the missing leg of the second-brain loop (spec Decision 36): capture
(`golem note`) and distill existed, but nothing closed ideas into **tasks** —
that happened ad hoc in conversation, invisible to the plan docs.

## What landed
- `docs/plan/BACKLOG.md` — a committed ideas inbox. One row per idea
  (Date / Idea / Source / Status), status flow `raw → discussed →
  promoted | dropped`. Human-editable; the agent only appends rows or bumps a
  status, and only through the plan-gate (Decisions 28/29). Promoted/dropped
  rows stay as a decision record.
- `/golem/plan` skill (`src/cli/skills.ts`, in `P0_SKILLS` so `golem init`
  installs it under `.claude/skills/golem/plan/`). Steps: (1) read-only gather
  — `golem note list`, `docs/wiki/questions/`, `.golem/distill/` drafts,
  `BACKLOG.md`, `ROADMAP.md`; (2) surface candidates grouped by source; (3)
  discuss; (4) propose BACKLOG/ROADMAP rows; (5) plan-gate every write; (6) the
  planning contract — cite a source per task, flag inference vs. stated intent,
  admit gaps rather than invent work.

## Notes
- Mirrors the [[llm-wiki-second-brain-obsidian]] plan-before-write ingestion
  contract, applied to task planning instead of page ingestion. See
  [[Wiki-First Knowledge]].
- Coder-first: drafted the skill with the `coder` local model, then rewrote it
  — the draft hallucinated "open browser" steps and mangled the frontmatter,
  and had the CLI as `golem note --list` (real subcommand is `golem note list`).
  A useful skeleton, not a finished answer; logged as an accept/revise data
  point for R4.3/R4.7.
- No frozen interfaces touched (skill string + a doc convention + tests).
