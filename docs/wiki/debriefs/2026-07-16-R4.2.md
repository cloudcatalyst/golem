The `coder` MCP tool sent the local drafter only `task` + optional
caller-supplied `context` — drafts were context-blind unless Claude hand-fed
code in. R4.2 makes drafting retrieval-augmented.

## What landed (`src/mcp/server.ts`)
- **Extracted `assembleHits(query, projectId, limit, deps)`** — the one place
  hit assembly lives (graph-first wiki lookup → vector search, de-duped → wiki
  boost → optional chat-judge rerank). `search` now composes it instead of
  inlining the pipeline; coder grounding composes the same function (R4.2's
  "compose, don't duplicate").
- **`gatherGrounding()`** runs `assembleHits` over the task text and packs the
  top hits into a size-capped, clearly-labeled context block appended to the
  drafter prompt. Budget: ≤4 hits, ≤4000 chars total, ≤1200 chars/hit — the
  drafter models are small, so the injected block stays modest.
- **`coder` tool gains `ground` (default true) and `project_id` inputs.** The
  structured output gains an optional `grounding: { sources, injected_chars }`
  so the caller can judge the draft's grounding; the text line notes "Grounded
  on N local source(s)".
- **Graceful degradation:** no KB wired, no hits, or any search failure →
  today's ungrounded behavior, never an error (grounding is best-effort).

## Notes
- `GolemMcpServerDeps` unchanged; grounding deps are passed to
  `registerCoderTool` from the already-present `knowledge`/`wikiSearch`/
  `wikiDir`/`rerank` fields (`wikiSearch ?? wiki`, same precedence `search`
  uses). No frozen interface touched.
- `exactOptionalPropertyTypes` required `?: T | undefined` on the new internal
  deps interfaces to pass the optional fields through.
- Coder-first: drafted `gatherGrounding` with the local model, then rewrote —
  the draft used `console.error` (must degrade silently), didn't guard an
  undefined `startLine`, and broke out of the loop instead of truncating the
  snippet to fit the remaining budget. Another accept/revise data point for
  R4.7. (The running MCP `coder` won't reflect grounding until the session's
  MCP connection is refreshed — a rebuild+reconnect.)
