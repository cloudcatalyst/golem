Two legs, one task: close the capture → distill → **promote** loop, and clear
the accumulated wiki-lint debt promotion writes into.

## Promotion UX
- **`golem wiki promote`** (`src/cli/promote.ts`): `--list` (or no id) shows
  pending `.golem/distill/` drafts with provenance, target page, and age;
  `<id> [--yes]` promotes one. `runPromote` routes the draft to its zone by
  `type`, upserts via the append-and-refine `upsertPage` (Decision 29 — dated
  separator, union-merged frontmatter, never wholesale), then removes the
  consumed draft (`removeDraftFile`). Non-TTY refuses without `--yes`
  (Decision 26 consent; `PromoteRefusedError`), mirroring `runOllamaSetup`.
  Consent/preview are injectable seams so the whole flow is testable headless.
- Updated [[Distillation Pipeline]] with the promote stage.

## Wiki-lint cleanup (18 → 0)
- **Checker fix**: `golem wiki check` now strips fenced/inline code before the
  broken-link scan (`stripCode` in `src/cli/wiki.ts`), so schema examples like
  WIKI.md's `` `[[Page Title]]` `` no longer count as links.
- **17 real link repairs across dated pages** (mechanical path repair, prose
  left alone): appended the exact suffix to inexact synthesis titles
  (`… (level 1 vs level 3)`, `… (Decision 32)`), removed stray backticks inside
  a couple of link titles, joined one link split across a newline, and aliased
  short refs (`[[full title|R2.6]]`) so prose display is unchanged. Added a
  minimal genuine wikilink to the three link-less pages (R2.2, R2.4 debriefs,
  the r1.6 question).
- **CI**: added a `wiki check` step to `.github/workflows/ci.yml` (the
  Decision 28 risk-table suggestion) so the graph can't silently rot again.
