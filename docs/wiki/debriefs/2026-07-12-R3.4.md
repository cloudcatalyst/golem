# R3.4 — user-scope wiki federation + weekly synthesis reports

**Before:** the wiki (spec Decision 28) was strictly project-scoped —
`docs/wiki/` (or wherever `knowledge.wiki_dir` points), one per repo. Spec
Decision 20e phases in a user-scope tier starting at P1 (local, alongside the
KB), with workspace/org sync deferred to P4+ hosted. Nothing existed at that
local tier yet, and there was no way to tie a period's scattered debriefs and
notes into one narrative without a human doing it by hand.

## What was built

- **`FederatedWikiReader`** (`src/wiki/federated-wiki-reader.ts`, new) — a
  read-only `WikiReader` merging a project reader and a user-scope reader.
  User-wiki `relPath`s get a `user:` prefix (`USER_WIKI_PREFIX`) so they can
  never collide with a project path; a title collision favors the project
  page; `backlinks()` is computed over the merged page set (not delegated
  per-reader) so a wikilink can cross between the two wikis. Writes are
  explicitly out of scope — `upsertPage` always targets the single project
  `WikiStore`.
- **`defaultUserWikiDir()`** (`src/cli/wiki.ts`) — `~/.golem/wiki/`, built on
  the pre-existing `defaultUserDir()` cross-platform home-dir resolver
  (`src/config/paths.ts`) with zero new path-resolution code needed.
- **`golem wiki init --user`** — scaffolds the user-scope wiki the same way
  `golem wiki init` scaffolds a project one, reusing `golemWikiInit`
  unmodified.
- **`GolemMcpServerDeps.wikiSearch`** (`src/mcp/server.ts`, new optional
  field, not a frozen interface) — the read surface `search`/`fetch` actually
  query, defaulting to `deps.wiki` when unset. `golem mcp serve` builds it as
  a `FederatedWikiReader` over the project + user wikis when
  `knowledge.user_wiki_enabled` (new settings leaf, default `true`) is on.
  `registerWikiTools` (the write surface, `wiki_read`/`wiki_upsert`) still
  binds to `deps.wiki` only.
- **`synthesizeWeekly`/`SynthesisInput`/`SynthesisDraft`**
  (`src/knowledge/distill.ts`) and **`writeSynthesisDraftFile`**
  (`src/knowledge/distill-store.ts`) — a third distillation flow alongside
  `distillPage`/`distillNote`, drafting a weekly through-line narrative over
  recent `debriefs/` pages and captured notes. **`listNotesSince`**
  (`src/cli/notes.ts`) gathers the note side of that window.
- **`golem wiki synthesize [--days N]`** (`src/cli/synthesize.ts` +
  `src/cli/main.ts`) — the CLI entry point, mirroring `distillOne`'s
  gather/construct-inference/call/write shape. Errors with a clear message
  (not a crash) when the window has neither debriefs nor notes.

## Design decisions

**A second, non-frozen `wikiSearch` field instead of touching the frozen
`WikiStore`/`WikiReader` contracts.** `GolemMcpServerDeps.wiki` was serving
two incompatible jobs: the read-only federated search surface, and the
write-restricted-to-project authoring surface. Rather than extend the frozen
interfaces (which would require deciding where a federated `upsertPage`
should even write — explicitly out of scope here) or bolt federation onto
`wiki` itself, `wikiSearch` is a plain optional field on the *deps* struct
(not an `src/interfaces/*` contract), defaulting to `wiki`. Cheap to add,
cheap to remove, no dependent-workstream flagging needed.

**Reused the graph-first search machinery unchanged.** `pageToHit`'s
`sourcePath` construction (`${wikiDir}/${page.relPath}`) and
`isUnderWikiDir`'s prefix check compose correctly with `user:`-prefixed
relPaths without any code change, because that machinery only depends on the
generic `WikiReader` interface and treats `relPath` as opaque. Verified this
by direct code reading rather than assuming — the only touches needed were
the two wiring points.

**`synthesizeWeekly` reuses `distillResultSchema` directly**, no new zod
schema — a `SynthesisDraft`'s shape (`title`, `slug`, `tags`, `summary`,
`wikilinks`) is structurally identical to `DistillDraft`'s; only the JSON-
schema description text and prompt content needed to be synthesis-specific.

**`synthesizeWeeklyReport` errors on an empty window (no debriefs AND no
notes)**, not just no debriefs — a synthesis over a quiet week with only
scattered notes is still worth drafting.

## Known gaps

`delegate` (local model) was unreachable when first attempted for this task
("could not reach inference endpoint: Headers Timeout Error") — noted per
CLAUDE.local.md's explicit fallback and both pieces were written directly
without further retry.
