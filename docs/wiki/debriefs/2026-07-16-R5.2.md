# R5.2 — Dashboard-as-sidecar completion (WS-F10 / spec 21c)

First task of the R5 batch (hold lifted 2026-07-16). The memo scoped this as
~70% done: statusline, dashboard server, session-state plumbing, and the VS Code
panel already shipped. R5.2 closed the two remaining gaps.

## What shipped

1. **One consolidated session-state read model** — `src/cli/session-report.ts`
   (`SessionStateReport` + `sessionStateReportSchema` zod contract +
   `collectSessionStateReport`). Before this, the sidecar state was split across
   two divergent shapes: the dashboard's savings-focused `DashboardSnapshot` and
   the status line's liveness-focused `GolemState`. The new payload unifies
   proxy reachability + upstream identity, slider level + **redaction-off flag**
   (Decision 30 loud-warning surfacing), local-model reachability, blocked/waiting
   flag, cumulative savings + per-stage/CCR/tool attribution, and on-disk storage
   sizes. It *composes* the shipped collectors (`collectGolemState`,
   `collectStats`, `getSliderInfo`, telemetry) rather than re-deriving — every
   source is guarded so one failure degrades a field, never the whole report
   (`null` = unknown, distinct from a confirmed `false`).

2. **`golem watch`** — `src/cli/watch.ts`: the one missing renderer. A full-screen
   TUI (`renderWatchFrame` pure fn + `runWatch` alt-screen loop) polling the
   consolidated API, for when one status-line row isn't enough. **Hand-rolled
   ANSI, zero new deps** (CLAUDE.md hard rule — no TUI lib in the default
   install); ESC built at runtime via `String.fromCharCode(27)`.

3. **Storage sizing** — `src/cli/storage-size.ts`: cross-platform recursive
   `dirSizeBytes` + `golemStorageSizes` over the four `.golem/` stores (ccr /
   knowledge / telemetry / webcache), fully defensive (missing dir → 0).

4. **The dashboard server exposes the shared payload** at `/api/state`
   (`src/dashboard/server.ts`, optional `sessionState` provider — backward
   compatible, 404s when unwired). This is the contract the future 21b remote
   app consumes; the existing HTML page + `/api/stats` are untouched.

## Verification

- +14 tests (storage-size 3, watch 6, session-report 3, dashboard 2). Full
  suite **952 green**; `tsc --noEmit`, biome lint + format clean.
- Driven end-to-end on the real repo: `collectSessionStateReport(cwd)` returned
  live data (proxy running → anthropic, L1 lossless / redaction on, local model
  reachable, 7451 telemetry requests with per-stage attribution, real storage
  sizes) and `renderWatchFrame` produced a clean frame.

## Notes / follow-ups

- No frozen interface touched. The payload is additive; renderers/remote app
  should validate with `sessionStateReportSchema` at their boundary.
- The web dashboard's HTML page still reads its own `DashboardSnapshot`; it
  *could* migrate to `/api/state` later, but that's cosmetic — the consolidation
  goal (one documented contract every renderer can share) is met.
- `golem watch` is a second-pane companion; the statusline stays the always-on
  one-liner. See [[Dogfooding Golem]] for the two-proxy dev setup.
