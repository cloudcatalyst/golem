# T4 — golem note capture

IMPLEMENTATION_PLAN §WS-W W3b / spec Decision 20f wanted frictionless
idea/note capture feeding the same future distill/review path as the wiki.
Nothing existed yet: no `note` command, no capture log.

## What changed

- `src/cli/notes.ts` (new): `appendNote`/`listNotes`/`renderNotes` — the same
  append-only-JSONL shape and corrupt-line tolerance as A4's telemetry store
  (`src/telemetry/jsonl-store.ts`), at `<project>/.golem/notes/notes.jsonl`.
  `appendNote` redacts with `stripKnownSecrets(pipelineRedact(text))` — the
  exact order the PostToolUse hook uses (CLAUDE.md hard rule: redact before
  storage, never weaken/reorder).
- `src/cli/main.ts`: new `note` command. `golem note "text"` captures (parent
  command's own `[text...]` argument + action); `golem note list [--json]
  [--limit]` reads it back, newest first. Confirmed live that Commander
  dispatches `note list` to the subcommand rather than treating "list" as
  literal note text.
- Capture is deliberately synchronous/dependency-free — no inference on the
  capture path, per the task's constraint. Distillation (T3) is what will
  later shape notes into draft `questions/`/`artifacts/` pages.

## Verification

New `tests/unit/cli/notes.test.ts` (8 tests): append/read round trip,
redaction (a fake AWS-shaped key, verified it disappears from both the
returned entry and the on-disk file), directory auto-creation, newest-first
ordering with `--limit`, and corrupt-trailing-line tolerance. Also drove the
built CLI directly in a scratch project: `golem note "..."` twice, then
`golem note list` and `golem note list --json`, confirming ordering and the
subcommand-vs-argument dispatch. Full gate: `tsc --noEmit`, `npm run lint`,
`npm run format:check`, `npm test` (72 files / 680 tests) all clean.

## Note

An earlier draft of this task's redaction test used an Anthropic-key-shaped
string as the fake secret; the platform's own safety layer (independent of
Golem) intercepts and rewrites that specific pattern in tool-call parameters,
which silently broke exact-string `Edit` matches downstream. Switched to an
AWS-key-shaped fake secret for the test fixture — same rule table coverage,
no interference.
