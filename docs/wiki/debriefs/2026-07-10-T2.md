# T2 — ship the missing wiki skills

IMPLEMENTATION_PLAN §WS-W W2 listed `/golem/wiki-query` and
`/golem/wiki-ingest <url>` as part of W2, but `src/cli/skills.ts`'s
`P0_SKILLS` only ever had slider/stats/expand/bypass — they were never
written, so `golem init` never installed them.

## What changed

Added two entries to `P0_SKILLS` (`src/cli/skills.ts`), following the
existing thin-prompt-delegating-to-frozen-MCP-tool-names pattern:

- `wiki-query` — `wiki_read` the topic first (title lookup), fall back to
  `search`/`fetch` (wiki hits already rank first there), answer with
  citations, and say plainly when nothing was found rather than falling back
  to general knowledge silently.
- `wiki-ingest` — fetch the URL (the WebFetch KB-cache hook captures raw
  content automatically), distill a source note in the model's own words
  (not a mirror/quote), **propose it and wait for approval**, then
  `wiki_upsert` into `sources/<slug>.md`. The plan-gating language
  (propose → approval → only then write) is load-bearing per spec Decision
  29 — it's what stops an agent writing to the wiki unprompted.

No other files needed changes: `golem init`'s skill-install loop and the
`golemInitStatus` check both iterate `Object.keys(P0_SKILLS)` generically, so
adding table entries was sufficient (the plan's "update tests that assert
counts" caveat didn't apply — none do).

## Verification

New `tests/unit/cli/skills.test.ts`: asserts `wiki-query`'s prose references
both `wiki_read` and `search`, and — more importantly — that `wiki-ingest`'s
approval instruction appears *before* its `wiki_upsert` call in the text, so
a future edit can't silently reorder the plan-gate away. Full gate: `tsc
--noEmit`, `npm run lint`, `npm run format:check`, `npm test` (71 files / 672
tests) all clean.

## Deviation from the plan

The plan suggested delegating the SKILL.md prose draft to the local model.
Written directly instead — the task is a handful of short, precision-worded
paragraphs (the plan-gating wording especially needs to be exact), and for
output this short a draft-then-correct round trip through the 7B drafter
wouldn't have been faster or better than writing it directly.
