The R2.1 spike (verification-notes §59) found the local knowledge/coder MCP
tools entirely uninstrumented — Golem could not say what they save. R4.3
closes that gap so "token-friendly co-developer" is a measured claim
(Decision 23's evidence-first rule).

## What landed
- **New `kind: "tool"` telemetry event** (`src/telemetry/types.ts`) with additive
  optional fields `tool`, `toolDurationMs`, `toolResultBytes`, `toolModel`,
  `toolDraftChars` — same absent-parses-as-0 backward-compat convention as the
  existing `avoidedUpstream`/`usage` kinds. Never counts toward `aggregate()`'s
  `requests`/gross-token headline.
- **`recordToolCall` helper** (`src/telemetry/index.ts`) + **`aggregateToolUsage`**
  on the store (`ToolUsageStats`: per-tool calls, total duration, result bytes,
  and the drafted-locally char bucket).
- **MCP instrumentation** (`src/mcp/server.ts`): a tiny `instrumented(tel, name,
  startMs, result)` wraps each success return of `search`/`fetch`/`ingest`/
  `wiki_read`/`coder`. For `coder` it also captures the model and draft length —
  tokens the paid model did not generate. Fire-and-forget: a telemetry write
  never delays or fails the tool result. `deps.telemetry` is a new non-frozen
  optional dep; `golem mcp serve` now shares one store between the compression
  wrapper (retrieval events) and tool events.
- **Surfaced in both `stats` surfaces**: the `stats` MCP tool gains an optional
  `tool_usage` map + a "Local tools: …" text line (with ~chars/4 drafted-locally
  token estimate); `golem stats` renders a "local tools:" section (per-tool
  calls, avg latency, drafted tokens). Both degrade to nothing when no tool
  events exist.

## Notes
- Scope: only the five tools R4.3 names, and only their success returns —
  error/throw paths aren't counted (they carry no result-size/draft signal).
  Honest limitation, noted here.
- `exactOptionalPropertyTypes` bit twice: the `instrumented` generic had to
  constrain `content` (not just `structuredContent`) or the SDK's `type:"text"`
  literal widened to `string`; and the new optional report/deps fields needed
  explicit `| undefined`.
- Verified end-to-end: built, seeded tool events, ran `golem stats` and saw the
  "local tools" section render (`coder … ~400 tokens drafted`).
- This is the baseline R4.7's accept-rate measurement will track over time.
