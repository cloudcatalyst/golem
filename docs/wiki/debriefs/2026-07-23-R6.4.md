First task off the R6 build order (see the R6 design memos —
`docs/plan/proposals/r6-multi-provider-remote-memos.md`). R6.4 was the only R6
task with no 🔒 security/ToS gate, so it went first. It makes spec Decision 21f
(adopt Claude Code's "Manage costs effectively" doc as explicit benchmarks) real
without touching the proxy path or any credential/adapter surface.

## What landed

- **`src/telemetry/cost-benchmark.ts` — pure, read-only composition.**
  `buildCostBenchmark(events, {projectId?, window, nowMs, claudeMdLines?})` folds
  the telemetry Golem *already* records into a report: R1.1 net-of-cache `usage`
  (via `effectiveInputTokens`, cache write 1.25× / read 0.1×), R2.2/R2.3
  `avoidedUpstream` in/out tokens, CCR store activity, and R4.3 per-tool `tool`
  events (with a per-tool share-of-calls attribution — the doc's "% of total").
  No new capture. `nowMs` is injected (the store never reads the clock).
- **`windowStartMs` + `BenchWindow` (`24h`/`7d`/`all`)** — the doc's own `/usage`
  time toggle.
- **`readTelemetryEvents(projectDir)` (`jsonl-store.ts`)** — additive raw-event
  reader (reuses `parseEvent`; ENOENT → `[]`) the benchmark needs to window by
  timestamp, which the kind-specific `aggregate*` rollups don't expose.
- **`golem bench cost [--window] [--project] [--json]`** (`src/cli/main.ts`) —
  best-effort reads (telemetry / CLAUDE.md failures degrade the report, never
  fail the command); JSON or human render.
- **CLAUDE.md-leanness check** — the doc's "keep CLAUDE.md under 200 lines" tip
  as a cheap, computed metric.

## The honest-scoping discipline (the point, not a footnote)

Decision 21f explicitly warns against a repeat of the §31 "91%" artifact, so the
report is built to *not* overclaim (verification-notes §72):

- It measures **Golem's own contribution** (CCR offload, local drafting,
  avoided-upstream, net-of-cache usage) — it is **not** a replacement for Claude
  Code's `/usage` per-user billing, which is computed from local session history
  Golem never parses. Golem also cannot see Claude Code's per-subagent/skill/
  plugin split — an honest gap stated in the report's `notes`.
- The doc's baselines (~$13/dev/active-day, $150-250/month, <$30/day for 90%,
  7× agent teams) are carried as **reference constants**, labelled "not a claimed
  delta". They moved since Decision 21f's 2026-07-04 fetch — re-verified 07-23.
- Only net-of-cache figures are reported (Decision 23/31): on caching upstreams
  lossless compression is ~0%, so the levers counted are CCR/local/avoided, never
  gross-token compression.

## Scope / interfaces

No frozen `src/interfaces/` change; no proxy-path change (pure observability,
like R1.1/R4.3). `readTelemetryEvents` is an additive module-level export, not a
`TelemetryStore` interface method, so test fakes were untouched. +11 unit tests
(fold-by-kind, cache multipliers, windowing + unparseable-ts skip, project
scoping, CLAUDE.md check, notes/baselines, render, reader round-trip). Suite
1159 → 1170 green; tsc/biome/format clean. Smoke-tested on this repo's real
dogfooding telemetry.
