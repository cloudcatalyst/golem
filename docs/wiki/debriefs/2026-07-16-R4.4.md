One-shot drafts from a small local model are hit-or-miss. R4.4 adds an
opt-in single refinement cycle, expressed entirely with the already-frozen
`InferenceService.chat()` + `jsonSchema` mechanism (the Decision 34 pattern) —
zero interface changes.

## What landed
- **`src/mcp/coder-refine.ts` — `refineDraft(inference, task, draft)`**: critique
  the draft with the `judge` role (forced JSON verdict: `hasIssues`, `summary`,
  `issues[{severity, description}]`); if it flags a high/medium issue, revise
  once with the `drafter` role; return `{ text, rounds, critiqueSummary,
  issues }`. Capped at one cycle. Best-effort like rerank: malformed JSON,
  unreachable model, or an empty revision all fall back to the original draft
  with `rounds: 0` — never throws (the draft already succeeded).
- **`coder` tool gains `refine` (default off)**: it multiplies local latency,
  so it's opt-in. Output gains an optional `refinement: { rounds,
  critique_summary, issues }`; the text line notes what happened.
- **Hardened `/golem/develop`** (`src/cli/skills.ts`): grounding is now
  automatic (R4.2), so stop hand-feeding context; pass `refine: true` for
  non-trivial drafts; and **skip `coder` entirely for trivial edits** — the
  round trip must pay for itself (CLAUDE.local.md).

## Notes
- The R4.3 telemetry measures the *final* (possibly revised) draft length, so
  the drafted-locally bucket stays honest with refinement on.
- Coder-first: drafted the refine module with the local model, then rewrote —
  the draft conflated the JSON Schema with a zod schema (jsonSchema forcing
  wants a plain JSON Schema, parsed separately with zod) and used
  `console.error`. Logged for R4.7.
- No frozen interface touched (composes `chat()` + `jsonSchema`, like rerank
  and distill).
