# R8.8 — price and context limits as Golem's own data

**Verdict: shipped.** `golem bench cost` reports real money; `golem stats --context`
says how much of the model's window a request used; `golem models` shows where every
number came from and when. The design work was almost entirely about the failure
modes, because this is the feature where being confidently wrong is worst: a cost
report is a credibility claim.

## The finding that set the architecture

models.dev's **web table** renders `claude-opus-5`, `claude-sonnet-5`,
`claude-fable-5` and `claude-opus-4-8` at **`$0.00 / $0.00`** (checked 2026-07-31).
Its **JSON API** is correct — `cost.{input,output,cache_read,cache_write}` and
`limit.{context,output}`, 175 providers, 5,900 models. Had the catalog been built by
scraping the obvious surface, Golem would have priced this project's entire Opus
traffic at zero and reported it as a measurement.

So the catalog is **two layers with the built-in winning**:

1. `BUILTIN_MODEL_CATALOG` — 7 Claude ids Golem enters by hand from Anthropic's
   published pricing, with a `source` and an `asOf`. Same pattern as
   `COST_DOC_BASELINES`: a cited constant, not a dependency.
2. An optional cache of a models.dev-shaped catalog, fetched **only** by
   `golem models refresh`. It fills gaps and can never overwrite a built-in entry
   (`mergeCatalogs`), so a third party's mistake cannot reach a cost claim.

Nothing fetches implicitly. A report that makes a network call is a report that can
be slow, wrong, or offline for reasons that have nothing to do with the numbers.

## Every way it can fail to know, kept visible

The rule is *a wrong price is worse than no price*, so nothing collapses to zero:

| case | what the report says |
|---|---|
| sample carried no model | counted as **unattributed**, never priced |
| id not in the catalog | row printed with the id **verbatim**, `usd: null`, `unknown` |
| id under two providers | `ambiguous` — no coin flip between two prices |
| one entry, different provider | priced and **labelled** `provider-unconfirmed` |
| entry with no price | `unpriced`, tokens still reported |
| catalog older than the limit | figures printed, header says **STALE** |
| no catalog at all | exactly R6.4's token-and-baselines report |

`claude-sonnet-5` carries a `note` naming its introductory window — a price with an
expiry that prints without one is a trap for whoever reads the report in September.

## The bug that matters more than the feature

`parseEvent` in `src/telemetry/jsonl-store.ts` is a **field-by-field allow-list**. The
proxy wrote `model`/`modelProvider` on every usage sample and `golem bench cost`
reported all 1,503 of them as unattributed, because the reader dropped the fields on
the way back in. Unit tests were green throughout — they feed objects straight to the
aggregator.

This is the **third** time: R8.1's cache verdict, R8.13's bust index, now the billed
model. The round-trip test in `tests/integration/cache-verdict-roundtrip.test.ts`
covers the model fields now, and the rule stands in the file's own comment: **a new
`TelemetryEvent` field needs a line in `parseEvent` AND a case in that test**.

It was caught by running the real command against real telemetry. Nothing else would
have caught it.

## First live numbers

- Spend, 24h, 20 attributed samples: `in 40 / write 12,359 / read 9,627,462 /
  out 4,738` → **$5.01**. About **96% of the bill is cache reads** at 0.1×, which is
  §93's "83% of input cost is re-reading" restated in money.
- Context window: `claude-opus-5: ~326,599 of 1,000,000 (32.7%) — within the window`.
- The 1,501 samples recorded before the proxy tagged the model stay **unattributed**
  rather than being priced against an assumption.

## What shipped

`src/telemetry/model-catalog.ts` (catalog, lookup, pricing, context warnings,
fetch + `.golem/state/model-catalog.json` cache, merge), a `spend` section on
`CostBenchmarkReport`, `model`/`modelProvider` on usage telemetry, `model` on the
context ledger, `golem models list|refresh` (`src/cli/models.ts`), and a `models`
config section (`catalog_url`, `catalog_max_age_days`, `context_warn_fraction`).

**No new spec Decision.** R8.8 obeys [Decision 49] (ids verbatim) and Decision 53's
tier ladder (3b: own data, cite the source, copy nothing) rather than changing either.
