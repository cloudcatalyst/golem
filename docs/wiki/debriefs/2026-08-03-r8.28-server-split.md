# R8.28 — mcp/server.ts split into 9 domain modules

**Verdict: shipped.** 2,213→130 lines. Barrel unchanged. No behavioral change.

## Problem

`src/mcp/server.ts` was 2,213 lines mixing 10 distinct concerns: tool registrations (expand, stats, level, search, fetch, ingest, wiki_read, wiki_upsert, coder, code, devices, snooze), all 8 prompt registrations, the LSP mode handler + schema, hit assembly (`assembleHits`), grounding (`gatherGrounding`), wiki boost, graph-first lookup, refine-outcome note formatting, and the instrumented telemetry wrapper. Identified by the fresh-eyes audit.

## What was extracted

| Module | Responsibility | Size |
|---|---|---|
| `deps.ts` | `GolemMcpServerDeps` + `createStandaloneDeps` | 143 lines |
| `shared.ts` | Constants, `textResult`/`errorResult`, instrumented telemetry wrapper | 93 lines |
| `search.ts` | search/fetch/ingest + hit assembly + wiki boost + graph-first lookup | 529 lines |
| `wiki-tools.ts` | wiki_read/wiki_upsert | 166 lines |
| `coder-tools.ts` | coder (draft, edit, refine) | 291 lines |
| `code-tool.ts` | code tool + LSP modes | 243 lines |
| `prompts.ts` | all 8 prompt registrations | 169 lines |
| `devices-snooze.ts` | devices + snooze tools | 246 lines |
| `server.ts` | wiring only: `createGolemMcpServer`, registration loop | 130 lines |

All exports from `src/mcp/index.ts` remain importable: `createGolemMcpServer`, `createStandaloneDeps`, `GolemMcpServerDeps`, `Grounding`, `HitAssemblyDeps`, `boostWikiHits`, `gatherGrounding`.

## What was preserved

- **Barrel unchanged** — no consumer (`serve.ts`, CLI, tests) needed a re-import.
- **No behavioral change** — tool/prompt registration order is identical; all 147 MCP tests pass.
- **Build green**: `tsc --noEmit` clean (3 pre-existing errors), `biome check` zero new findings, `npm run test` 185/186 files (2250/2252 tests).

## Key lesson

A file at 2,200+ lines accumulates because each new tool registration or prompt handler is a ~30-line addition that "doesn't justify a new file." The threshold needs to be lower in a codebase that adds MCP tools regularly — ~500 lines is the new ceiling for `src/mcp/` modules. Commit `1533bd2`.
