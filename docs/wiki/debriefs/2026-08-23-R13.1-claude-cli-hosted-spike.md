# Debrief: R13.1 — Claude CLI hosted session spike

## Outcome
Confirmed that `claude` CLI v2.1.235 can be driven as a hosted session via separate-invocation chaining (`--continue` / `--resume <sid>`). Golem's hooks fire in non-bare `-p` sessions, confirming enforcement invariant is enforceable. Multi-turn stdin mode remains unestablished.

## What worked
- Separate-invocation chaining with stable session IDs across process restarts
- Golem PostToolUse and PreToolUse hooks firing in hosted `-p` sessions
- Stream-json structured output for event-driven processing
- `--bare` flag for fully isolated runs (no hooks/settings/CLAUDE.md)

## What did not work
- Multi-turn stdin (`--input-format stream-json --output-format stream-json`) — could not reproduce under standalone conditions
- Proxy interposition proof in throwaway context — direct connection hung
- SIGINT interruption on Windows — turns resolve too fast

## Surprises
- Hook overhead nearly doubles cost ($0.15 -> $0.34 per invocation)
- Default permission mode allows tools without prompting in `-p` (no PTY available)
- `auto` permission mode timed out, possibly due to account criteria

## Lessons
- Live testing beats reading docs or prior claims — the multi-turn stdin story contradicts observed behavior
- Worktree isolation complicates git operations; always use absolute paths for repo-root files
- Small bash heredocs (~20 lines) succeed reliably; large ones fail silently — split accordingly
