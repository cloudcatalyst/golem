Final slice of case (b), built after a checkpoint (user go-ahead). Gemini is a
**second upstream schema** — not OpenAI Chat Completions — so it needed its own
translator plus a proxy-seam extension. API was verified first (§77) per the
CLAUDE.md verify-before-build rule.

## What landed

- **`src/providers/gemini-translate.ts`** — `anthropicToGemini` (→ `contents`
  with `role:"model"` for assistant; `parts` text/`functionCall`/`functionResponse`;
  `systemInstruction`; `generationConfig` {maxOutputTokens,temperature,topP,
  stopSequences}; `tools[{functionDeclarations}]`;
  `toolConfig.functionCallingConfig`), `geminiToAnthropic` (candidates→text/
  `tool_use`, `usageMetadata`→usage, tool_use stop_reason from a functionCall
  part), and `geminiPath` (`/v1beta/models/{model}:generateContent` or
  `:streamGenerateContent?alt=sse`, `?key=` appended). Tool round-trip: a
  `tool_result`'s function name is recovered from the request's earlier
  `tool_use` blocks (Gemini `functionResponse` needs the name; Anthropic
  `tool_result` only has the id).
- **`src/providers/gemini-stream.ts`** — `GeminiSSETranslator`: Gemini SSE →
  Anthropic event stream, same sequential-block discipline as the OpenAI one.
  Gemini sends whole `functionCall` parts (not fragmented), so each becomes a
  `tool_use` block + one `input_json_delta`. (Block machinery is duplicated from
  openai-stream.ts to keep that shipped translator untouched — a future refactor
  could extract a base emitter.)
- **Seam extension** (`UpstreamTranslator`): `translateRequest` may now return a
  per-request `path`. Gemini needs it — its auth is a **query param** (`?key=`,
  not a header, so `mapUpstreamHeaders` can't carry it) and the path embeds the
  model + method + `alt=sse`. OpenAI leaves `path` undefined → uses the fixed
  `translate.path` (unchanged).
- **Provider `gemini`** wired (`isGeminiProvider`, translating, non-caching, no
  header auth; key from `GOLEM_UPSTREAM_API_KEY` → the `?key=` param; startup
  warning if unset). Base URL: `https://generativelanguage.googleapis.com/v1beta`.

## Verification

- **+14 tests**: request (contents/system/config/tools/tool_choice + tool
  round-trip), `geminiPath` (stream/non-stream/key), non-streaming response
  (text + functionCall → tool_use), streaming (text then whole functionCall →
  separate blocks), provider helpers, and a **proxy integration test** proving
  the per-request path override (`…:generateContent?key=KEY` and
  `:streamGenerateContent?alt=sse&key=KEY`) + Gemini↔Anthropic round-trip through
  the real proxy, non-streaming and streaming. Suite **1222** green (no flake this
  run); tsc/biome/format/wiki clean.
- **Not live-tested** — no Gemini API key in-session. A real end-to-end check is
  a user-side step (same posture as OpenAI-cloud and the R7.3 binaries).

## Scope / interfaces

No frozen `src/interfaces/` change. `UpstreamTranslator` (non-frozen proxy type)
gained the optional per-request `path`. Anthropic passthrough and the OpenAI
translator are unchanged.
