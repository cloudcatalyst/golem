## Goal

A models.dev-style catalog — fetched and cached, **tier 3b** (Golem's own data, no
runtime dependency, cite the source, copy nothing). Turns `golem bench cost` into real
money instead of reference baselines, and enables correct context-limit warnings.

## Why

R6.4 shipped `golem bench cost` framed against *re-verified reference baselines*
(§72), which is honest but weaker than it needs to be: the telemetry already knows
token counts, so the only missing input is price. Context limits are the second
payoff — a warning that a request is approaching the window is only possible with a
per-model number.

## The constraint that has bitten before

**Decision 49: model ids print verbatim.** The catalog attaches price and context to
an id; it must never substitute a friendly name, and a model missing from the catalog
must render as its raw id with no price rather than as an error or a guess.

## Hard constraints

- Tier 3b: fetched-and-cached data, offline-tolerant, no new runtime dep.
- A stale or absent catalog degrades to today's behaviour (reference baselines), never
  to a wrong number. Cost claims are this project's credibility.
- Cite the upstream source in the cached artifact.

## Out of scope

A curated model marketplace. Recommending models. Anything that routes on price —
quota-evasion routing is ToS-OUT per ADR-0003.
