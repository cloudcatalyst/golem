## Goal

Let a failed attempt be **discarded** instead of repaired. Opt-in shadow git refs —
**not** real commits — so the model can throw away a bad path rather than spending
context unpicking it, and the user gets `/undo` parity with OpenCode.

## Why it is a context-economy task, not a git feature

A failed attempt that has to be *repaired* costs a full read-diagnose-edit cycle and
leaves the wreckage in the context window for every subsequent turn (§93: ~83% of
input cost is re-reading). Discarding is cheaper than repairing, and today there is no
mechanism for it.

## The rule this must not break

**This repo commits only when asked.** So: shadow refs (`refs/golem/...`), never
commits on the user's branch, never a staged index, never a `checkout` that discards
uncommitted work the user did not ask to discard. Opt-in, and loud about what it will
do before it does it.

## Hard constraints

- Cross-platform git invocation via argument arrays, no shell strings.
- A repo with no git, a detached HEAD, or a dirty index must degrade to a no-op with
  a clear reason — never a partial revert.
- Reverting is destructive and outward-adjacent: it goes through the autonomy gate
  (ADR-0002).

## Out of scope

Session branching (that is R8.S3). Replacing git. Anything that rewrites history.
