## Goal

Three defects found while diagnosing "the VS Code status bar says Poolside but that
isn't the upstream we're using". They are independent; the first is the one that
produced the reported symptom.

**1. `golem proxy status` reported the wrong upstream.** `resolvePort`
(`src/cli/program.ts`) returned `settings.proxy.upstream_base_url` — the top-level
legacy leaf — so every `proxy status` / `proxy start` / `proxy restart` banner
announced `-> https://api.anthropic.com` while the proxy was correctly serving an
active OpenRouter account. The proxy itself was never wrong: `buildProxyFromSettings`
resolves the active account via `resolveActiveUpstream`. Only the display lied, which
reads as a failed `golem account use`. Fixed by resolving through
`resolveUpstreamDisplay(settings.proxy).baseUrl` — the same resolver, so the banner
cannot drift from the route again.

**2. Panel setting toggles were silently masked.** `controlRowHtml` rendered the
scope `<select>` in `writableScopes` order and marked nothing selected, so the browser
pre-selected the first option (`project`). Config precedence is
`default < user < project < local < env`, so toggling a setting whose value is owned by
the `local` layer wrote to `project`, `local` kept winning, and the next refresh snapped
the row back — the control looked dead. This is why `inference.local_coder_enabled`
could not be turned off from the UI. Fixed by pre-selecting the layer that owns the
value, falling back to the first option when that layer isn't writable (`default`,
`env`).

**3. "Switch upstream…" took ~2.8s to open.** `buildModel` normalized the account
list with `Array.isArray(accounts) ? accounts : []`, but
`golem account list --json` emits the `AccountsReport` **object**
(`{active, active_unknown, accounts:[…]}`). The cache was therefore always empty and
`pickAccount` fell through to a blocking CLI call — measured 2.6–3.0s, since
`collectAccounts` probes every account's credential store (DPAPI file decryption per
account on Windows). Fixed by accepting either shape.

## Out of scope

- The ~2.8s cost of `golem account list --json` itself. The unwrap removes it from
  the quick-pick's critical path, but `fetchModel` still pays it on the 15s poll.
  Worth a separate look at caching `store.status` if it shows up in profiles.
- Account credentials, DPAPI storage, proxy restart logic.
