## Goal

Give the model a **whole-repo, graph-ranked signature skeleton** rendered to a token
budget (default 1–1.5k), and use it as the **swap target for an oversized `Read`** —
skeleton + the requested range + a CCR ref, instead of 2000 lines.

## Why this is next by evidence

`golem stats --context` says `Read` is the second-biggest tool consumer (27,056
tokens across 18 results in the §95 capture; 40,708 across 20 in a later one) **and**
it is the surface a Bash-output compactor structurally cannot reach — RTK's hook only
fires on Bash (§90). §93 established that ~83% of input cost is re-reading an
already-cached context, so a read avoided pays on every subsequent turn, not once.

R8.S1 (§100) closed the tools-block line of work, which leaves this as the largest
un-attacked bucket Golem actually owns.

## Two delivery paths

1. **A `code` tool mode** — the model asks for the map.
2. **The oversized-`Read` swap** — the PostToolUse digest (R8.3, line-aware since
   §97) offers the skeleton alongside the excerpt.

Golem's edge over Aider's repo map: incrementally refreshed by the existing watcher
(ADR-0001), re-ranked against the live query via `assembleHits`, and **byte-stable
across turns** so it is cache-safe.

## Hard constraints

- **Byte-stable output.** The map renders into a cached prefix's neighbourhood; an
  unstable rendering re-prefills and is strictly worse than doing nothing.
- **One tool, modes not tools.** §88/§100 measured tool definitions as a permanent
  per-request bill. Add a single `code` tool with a `mode` parameter — never four new
  tools — and measure the delta with `golem bench tools` before wiring.
- tree-sitter is already a tier-2 optional dep (`src/knowledge/tree-sitter-chunker.ts`,
  Decision 53). Absence must degrade to a no-op, never an error path.
- Redaction before storage still applies to anything cached.

## Out of scope

- Per-file signature extraction as a product (RTK's `read -l aggressive` covers it —
  the differentiated part is the whole-repo graph-ranked map).
- Rebuilding RTK's Bash filters.
- Any change to `Read`'s own byte-faithful passthrough at slider ≤1.

## Definition of done

The harness reports saving **and** accuracy together, and the honest answer may be
"partially" — memo open question 3 asks whether the map actually *displaces* reads or
whether the model reads the file anyway. Record the number either way; a negative is
publishable (§89/§100 precedent).
