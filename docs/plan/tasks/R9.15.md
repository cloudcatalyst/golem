## Goal

The user has no pay-as-you-go API credit and asked whether `coder` can draft on
the quota they already have. It can — but only one of the two available routes
is legitimate, and the difference is the whole task.

**Not this.** Reading Claude Code's OAuth credential from its store, or replaying
the `authorization` header Golem's proxy already sees, to originate new requests
against `api.anthropic.com`. Proxying the user's own Claude Code requests is
Golem's job; minting requests Claude Code never made, using the credential issued
to it, is not. The spec already draws this line (§267): *account switching is
user-initiated and transparent, not covert evasion of limits.* Golem must never
read, copy or forward a Claude Code credential.

**This.** Spawn the official client headlessly. Official binary, official auth,
official quota accounting, nothing extracted — exactly Decision 53's shape.
Verified live on Windows before writing any code:

```
printf '<prompt>' | claude -p --model sonnet --output-format text \
  --no-session-persistence --strict-mcp-config
→ "ok" in ~7.0s (cold), subscription auth, ANTHROPIC_BASE_URL unset
```

## The two guards — the user's constraint, made real

The user asked for this to fire "only when the coder model is different from the
current model and it isn't using a 3rd-party upstream". No such gate exists
today: dispatch happens purely because `inference.worker_targets.coder` names a
target. Both guards are part of this task, and both **refuse** rather than
falling back — silent substitution is the failure mode this repo keeps closing.

1. **Upstream must be Anthropic.** If the session is fronted by a third-party
   gateway, the spawned client draws on a *different* account than the session,
   which is a surprise, not a saving.
2. **Model must differ from the session's.** Drafting on the same model the
   session is already using spends the same quota for a worse context. The
   session's model comes from `.golem/state/served-model.json`; when there is no
   snapshot the guard cannot prove sameness and allows the dispatch (documented
   fail-open, since the alternative is refusing on no evidence).

## Why spawn, and what it costs

- **Prompt on stdin, never argv.** The only variable argv element is the model
  id, validated against a conservative pattern. Nothing the model wrote is ever
  parsed by a shell.
- **Scrubbed environment.** `ANTHROPIC_*`, `GOLEM_*` and `ENABLE_TOOL_SEARCH` are
  stripped, so the child goes **direct** to Anthropic on OAuth rather than
  looping back through Golem's own proxy (which would both misroute the draft
  and risk re-entrancy), and never inherits a Golem credential.
- **Clean cwd, no tools.** Spawned in a temp directory with the file and exec
  tools denied — a drafting call must not read or write the project.
- **Redaction is unchanged.** A spawn is an egress, so the prompt is redacted
  before it and restored after, exactly as for an HTTP target.
- **It does not conjure quota.** It spends the same pool as the interactive
  session and competes for the same rate limit `snooze` parks on. Say so in the
  guidance surfaces rather than letting a user discover it at a limit.
- **~7s cold start per draft** against a local model's sub-second. Recorded, not
  hidden.

## Out of scope

- Any use of the proxy's observed `authorization` header, or of `~/.claude`
  credentials, for anything. Not a fallback, not an optimisation.
- Making `claude-cli` selectable as `proxy.upstream_provider` — it is a *target*
  provider only, and the proxy path must refuse it at config-load time.
- Streaming, tool use, or multi-turn in the spawned session. One prompt, one
  text reply.
- Changing the default `worker_targets`. The route is opt-in.
