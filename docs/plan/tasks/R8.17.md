## Problem

The `expand` tool handler catches only `UnknownRefError`:

```ts
try {
  const original = await deps.compression.retrieve(...);
  return textResult(original.content);
} catch (error) {
  if (error instanceof UnknownRefError) {
    return errorResult(...);
  }
  throw error;  // unhandled → kills the MCP process
}
```

If `retrieve()` throws for any other reason (corrupt blob on disk, EACCES, disk full, IO error), the throw propagates unhandled. In MCP's command server, an unhandled throw in a tool handler is equivalent to a process crash — Claude Code sees a closed connection.

## Fix

Replace the if-instanceof with a catch-all that maps all errors to `errorResult()`:

```ts
try {
  const original = await deps.compression.retrieve(...);
  return textResult(original.content);
} catch (error) {
  if (error instanceof UnknownRefError) {
    return errorResult(`Unknown or expired CCR ref "${ref_id}". ...`);
  }
  return errorResult(
    `Failed to retrieve content for ref "${ref_id}": ${
      error instanceof Error ? error.message : String(error)
    }`,
  );
}
```
