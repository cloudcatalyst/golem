## The measurement

Timing each step the proxy daemon performs before `listen()`, against this project:

```
     7ms  migrateOnVersionChange
    11ms  loadConfig
  6668ms  credentialEnvForProxy      <- 98% of pre-listen time
   118ms  detectCapability (hardware probe)
    22ms  resolvePersistedEmbedMode
    59ms  ollamaHasModel
```

Breaking `credentialEnvForProxy` down further:

```
     7ms  resolve(default)            miss
     1ms  resolve(anthropic)          miss
     2ms  resolve(sonnet-5)           miss
  3601ms  resolve(openrouter-qwen3)   HIT   <- includes the one-time DPAPI host self-test
   940ms  resolve(openrouter-gemma4)  HIT
```

An account with nothing stored costs ~1ms (the blob file is simply absent). Every account
that **does** have a credential costs a PowerShell spawn to DPAPI-decrypt it, plus a
one-time ~2.6s self-test that probes `powershell.exe` then `pwsh` with an encrypt/decrypt
round trip.

R9.18 made the per-account lookups concurrent, which helps platforms with a cheap helper
(`security`, `secret-tool`) but changes little on Windows: concurrent PowerShell startups
contend rather than overlap.

## Scope

- **Batch the decrypt.** One PowerShell invocation that decrypts every needed blob and
  returns them together, instead of one spawn per account. This is the fix that removes
  the cost rather than hiding it.
- **Consider caching the host choice.** The self-test exists to prove the host actually
  works; a cached answer keyed on the host binary's path+mtime would keep the guarantee
  while skipping ~2.6s. Weigh against the risk of a stale positive.

## Watch for

- Secrets must never reach a command line or a log — the current backend passes blobs on
  stdin for exactly this reason, and a batch call must keep that property.
- A single failing blob must not fail the whole batch: today an unresolvable account is
  skipped silently so the proxy still starts for the targets that ARE keyed.
- The proxy pays this cost twice per restart (parent builds the child's env, child resolves
  again). Worth asking whether the child can inherit rather than re-resolve.
