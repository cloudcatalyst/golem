## Goal

Serve the onboarding one-liner from `golem.run` and confirm the nginx user-agent map
actually routes the three clients correctly.

## State of play

`deploy/nginx/golem-run.conf` shipped with R7 (Decision 41b/41c) and maps
PowerShell / curl / browser user agents — with PowerShell matched **before** the generic
`Mozilla` rule, which is the subtle part and the thing most worth verifying live.
Nothing is deployed.

## What to confirm

- `curl -fsSL https://golem.run | sh` gets the shell installer.
- `irm https://golem.run | iex` gets the PowerShell installer, not the shell one and not
  the HTML page.
- A browser gets the docs page.

## Why this is the user's

DNS, TLS and a host are credentialed, outward acts.

## Out of scope

Building the docs site. Changing the installer ladder (npm → binary → Node bootstrap).
