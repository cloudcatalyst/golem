## Goal

Close the loop on prompt translation: score rewrites, learn from accepted ones, improve.

## Why it is not being built

R5.5 shipped as a **spike** and the debrief deliberately stopped short of the scoring
loop, on the grounds that a learning loop with no usage has nothing to learn from. The
translator itself works: local rewrite, always shown, never sent, off the proxy path,
few-shot on accepted examples (`golem prompt translate` / `golem prompt accept`).

This task exists so "we chose not to build it" stays distinguishable from "we forgot".

## What would unblock it

Usage. If `golem prompt accept` starts accumulating examples, there is something to
score.

## Out of scope

Building it on the assumption demand will appear.
