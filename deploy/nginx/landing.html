⬢ Golem

A universal pre-LLM processing layer — local-first proxy + MCP server for redaction, compression, local tools, and honest observability in front of your LLM traffic.

Install — macOS / Linux

curl -fsSL https://golem.run | sh

Install — Windows (PowerShell)

irm https://golem.run | iex

The installer prefers npm i -g golem-run when Node ≥ 22 is present, and falls back to a self-contained binary otherwise. Then run golem init. Prefer to read first? install.sh · install.ps1.

Docs & source: github.com/cloudcatalyst/golem
